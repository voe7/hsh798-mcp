# 惠生活798 MCP 工具服务

## 项目概述

该 MCP 工具主要面向 **惠生活798账号服务与设备管理场景**，提供了从账号登录、积分任务执行，到设备维护与设备控制的一整套能力封装。通过标准化的 Tool 接口，调用方可以使用自然语言或程序化方式完成常见业务操作，无需直接关心底层接口细节。

---

## 功能模块总结

该 MCP 工具可以划分为四大模块：

### 登录鉴权模块
- 发送短信验证码
- 验证码登录

### 账户与积分模块
- 查询积分
- 获取钱包余额
- 每日签到
- 广告任务
- 视频任务

### 本地设备管理模块
- 新增设备
- 查询所有设备
- 删除设备

### 远程设备控制模块
- 开启设备
- 关闭设备
- 常用设备管理

## 使用方式

### 1. 安装依赖

```bash
npm install
```
### 2. 启动服务

#### 开发模式：
```bash
npm run dev
```
#### 构建后运行：
```bash
npm run build
npm start
```
### 3. MCP 配置
#### 开发环境配置示例
```json
{
  "mcpServers": {
    "hsh798-mcp": {
      "command": "npm",
      "args": ["run", "dev"]
    }
  }
}
```
#### 构建后运行配置示例
```json
{
  "mcpServers": {
    "hsh798-mcp": {
      "command": "node",
      "args": ["dist/index.js"]
    }
  }
}
```
## 适用场景

该 MCP 工具适用于以下场景：

- 惠生活798账号自动化登录
- 日常积分任务自动执行
- 钱包与积分状态查询
- 本地设备台账维护
- 常用设备管理
- 指定设备远程启停控制
