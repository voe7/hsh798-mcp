# 惠生活798 MCP 工具服务

## 项目概述

该 MCP 工具主要面向 **惠生活798账号服务与设备管理场景**，提供了从账号登录、积分任务执行，到设备维护与设备控制的一整套能力封装。通过标准化的 Tool 接口，调用方可以使用自然语言或程序化方式完成常见业务操作，无需直接关心底层接口细节。

---

## 一、账号与登录能力

工具支持基于手机号的登录流程，包含两个核心步骤：

### 1. 发送登录短信验证码
- 向指定手机号发送登录验证码短信
- 登录前必须先调用该能力获取验证码

### 2. 验证码登录
- 使用手机号和 6 位短信验证码完成账号登录
- 登录成功后可继续调用积分、任务、设备等相关功能

这部分能力适合需要进行账号鉴权、会话初始化的业务场景。

---

## 二、积分与任务能力

工具支持查询当前账号积分情况，并执行平台中的日常积分任务，主要包括：

### 1. 查询积分信息
- 获取当前账号的积分数据
- 可覆盖可用积分、总积分等信息

### 2. 获取钱包余额
- 查询当前登录账号的钱包可用余额

### 3. 每日签到
- 执行每日签到任务
- 支持根据当前星期信息完成签到逻辑

### 4. 广告任务
- 执行一次“观看广告获取积分”任务
- 单日如需全部完成，需按任务次数重复调用

### 5. 视频任务
- 执行一次“观看视频获取积分”任务
- 单日如需全部完成，需按任务次数重复调用

这部分能力适合自动化积分运营、日常任务代执行、账户状态查询等场景。

---

## 三、设备管理能力

工具内置本地设备管理机制，设备信息存储于 `devices.json` 文件中，并支持以结构化方式进行维护。主要能力包括：

### 1. 新增设备
- 根据设备名称和设备编号新增设备
- 新增时设备 ID 可按已有数据自动递增

### 2. 查询所有设备
- 获取本地维护的全部设备列表

### 3. 删除设备
- 根据本地设备 ID 删除指定设备

### 4. 按条件检索设备
- 支持后续扩展按 ID、名称、DID 等维度查询设备信息

这部分能力适合做常用设备维护、设备台账管理、自动化控制前的数据准备。

---

## 四、设备控制能力

除了本地设备管理外，工具还支持对指定设备进行远程操作，包括：

### 1. 开启设备
- 根据设备 DID 开启指定设备

### 2. 关闭设备
- 根据设备 DID 关闭指定设备

这使得 MCP 工具不仅能“管理设备信息”，还能直接“操作设备状态”，适合构建自动化设备控制流程。

---

## 五、常用设备能力

工具还提供了常用设备相关功能，便于对高频设备进行快捷管理：

### 1. 获取常用设备列表
- 查询当前账号的常用设备集合

### 2. 设置/取消常用设备
- 将设备设为常用设备
- 或取消其常用状态

这部分能力适合在设备较多时，快速筛选和维护重点设备。

---

## 功能模块总结

整体来看，该 MCP 工具可以划分为四大模块：

### 登录鉴权模块
- 发送短信验证码
- 验证码登录

### 账户与积分模块
- 查询积分
- 获取钱包余额
- 每日签到
- 广告任务
- 视频任务

### 本地设备管理模块
- 新增设备
- 查询所有设备
- 删除设备

### 远程设备控制模块
- 开启设备
- 关闭设备
- 常用设备管理

---

## 适用场景

该 MCP 工具适用于以下场景：

- 惠生活798账号自动化登录
- 日常积分任务自动执行
- 钱包与积分状态查询
- 本地设备台账维护
- 常用设备管理
